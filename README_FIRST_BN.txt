FloodGuard AI — প্রথম ML Backend Update

এই ZIP-এ আছে:
- আগের ওয়েবসাইট index.html

পরবর্তী ধাপ: backend/README.md খুলে Windows setup অনুসরণ করো। আমি চাইলে পরের ধাপে তোমাকে dataset সংগ্রহ, station ID মিলানো এবং প্রথম training চালানোতেও গাইড করব।
